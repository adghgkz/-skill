
用于会议总结写作的 Agent Skill
文档输入：纯文本粘贴，或直接传入字符串。

智能结构化总结：

会议基本信息（日期、参会人、时长，若文档中未提供则智能推测或留空）

讨论主题与关键论点

达成的决策与共识

待办事项清单（含责任人、截止时间，若文中未提及则标注“待明确”）

遗留问题或后续步骤

上下文感知：能够识别文档中的讨论脉络，提取隐性决策点。

多语言支持：中英文混合文档均可处理，输出语言可配置（默认与输入一致或指定）。

多种输出格式：Markdown、纯文本、JSON，方便直接复制到 Notion、飞书、钉钉。

轻量集成：可作为一个独立的 LLM 智能体技能，嵌入 LangChain、AutoGPT、Dify 等框架。
